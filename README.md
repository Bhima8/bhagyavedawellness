# Bhagyaveda Naturals & Wellness — Website

A static, multi-page website built with plain HTML, CSS and JavaScript. No frameworks, no build tools required to view it, no database. It works on any web host.

**Ancient Wisdom | Modern Health**

---

## Quick start

1. Unzip the folder.
2. Double-click `index.html` to open it in your browser, or run a small local server from the folder:
   ```bash
   python3 -m http.server 8000
   # then open http://localhost:8000
   ```
3. Edit, save, refresh the browser.

Python 3 is only needed for the optional helper script `tools/build.py` (see [How to add or edit products](#1-how-to-add-or-edit-products)). Viewing and hosting the site does not need Python.

## 1. How to add or edit products

All products live in **`data/products.json`**. Each product looks like this:

```json
{
  "slug": "success-ortho",
  "name": "Success Ortho",
  "category": "bone-joint",
  "badge": "Top Selling",
  "form": "Sachet",
  "price": 450,
  "short": "One-line summary shown on cards.",
  "description": ["Paragraph one.", "Optional paragraph two."],
  "benefits": ["Benefit one", "Benefit two"],
  "ingredients": ["Methi", "Amla"],
  "features": ["Optional extra bullet list"],
  "dosage": ["Take 1 sachet with lukewarm water before breakfast."],
  "notes": ["Optional caution or advice shown in a highlighted box."]
}
```

- `slug`: lowercase letters, numbers and hyphens. It becomes the page name (`product-detail-<slug>.html`) and the image name (`gallery/<slug>.jpg`). Never use spaces.
- `category`: must match a category `id` at the top of the same file.
- `badge`: optional label such as "New", "Popular", "Top Selling", "Special".
- `price`: optional number. Leave it out and the page shows **"Contact for pricing"**. If you add `"price": 450`, it shows ₹450.
- Empty lists (`"ingredients": []`) are simply not shown.

### Edit an existing product
1. Change its entry in `data/products.json`.
2. Run `python3 tools/build.py` from the project folder.
3. Refresh the browser.

### Add a new product
1. Copy an existing product block in `data/products.json`, paste it before the closing `]`, and change every field. Put a comma between product blocks.
2. Save the photo as `gallery/<slug>.jpg` (about 800 × 800 px works well).
3. Run `python3 tools/build.py`. This creates `product-detail-<slug>.html`, updates `js/products.js` (which feeds the Products page, menu and the inquiry form drop-down), and refreshes the gallery list.
4. Optional: to show it on the home page, add its slug to `home.popular` or `home.trending` in `js/config.js`.

### Remove a product
Delete its block from `data/products.json` and run `python3 tools/build.py`. The stale page is deleted automatically.

### Add or rename a category
Edit the `categories` list at the top of `data/products.json` (`id`, `name`, `blurb`, `image`). Put the circle picture at `gallery/<image>`. Run `build.py`.

### No Python available?
You can still work without it:
1. Add the product to `js/products.js` by hand, following the same structure.
2. Open it at `product-detail.html?product=<slug>`. This template page builds itself from `js/products.js`.
3. Link to that address from anywhere you like.

## 2. How to change colours, fonts and theme

Open **`css/style.css`**. The first block, `1. THEME VARIABLES`, controls the look of the whole site.

```css
:root {
  --color-primary:      #2e7d32;   /* header green */
  --color-primary-dark: #1b5e20;   /* top bar, footer, hover */
  --color-primary-soft: #e8f5e9;   /* light green section backgrounds */
  --color-accent:       #c9a227;   /* gold (buttons, badges) */
  --color-bg:           #fefbf3;   /* page background (cream) */
  --font-heading: "Fraunces", Georgia, serif;
  --font-body:    "Nunito Sans", system-ui, sans-serif;
  --radius: 14px;
  ...
}
```

- **Colours:** change the hex values. Everything updates.
- **Fonts:** fonts come from Google Fonts. To switch, (1) pick fonts at fonts.google.com, (2) replace the `<link ... fonts.googleapis.com ...>` line in the `<head>` of every page, and (3) update `--font-heading` / `--font-body`. The `<head>` line for product pages is in `tools/build.py` (variable `HEAD`); the other pages are plain HTML files. Run `build.py` afterwards. To use no web fonts at all, delete those `<link>` lines; the fallback fonts in the variables take over.
- **Spacing and roundness:** `--space-*`, `--radius`, `--radius-lg`.
- **Header height:** `--header-h`.
- **Page width:** `--container`.

Each section of the stylesheet is labelled (header, footer, home page, product cards, and so on) so you can find things quickly.

**Home page banners, feature strip and product picks** are in `js/config.js` (`hero`, `features`, `home`).

## 3. How to update contact information

Open **`js/config.js`** and edit the `contact` block:

```js
contact: {
  phoneDisplay:   "+91 93226 54624",   // what visitors see
  phoneTel:       "+919322654624",     // used for the call button (tel:)
  whatsappNumber: "919322654624",      // country code + number, no + and no spaces
  email:          "",
  addressLines:   ["M/P Boramani, Hyderabad Road", "Solapur 413002"],
  hours:          "",
  mapEmbedUrl:    "https://www.google.com/maps?q=Boramani,+Hyderabad+Road,+Solapur+413002&output=embed"
}
```

This one place updates the top bar, footer, contact page, floating buttons, inquiry form and WhatsApp links on all pages, including the generated product pages.

- **Change the map pin:** edit the text after `q=` in `mapEmbedUrl`. Or, in Google Maps, choose Share → Embed a map, copy the `src="..."` value and paste it in. Set it to `""` to remove the map.
- **Social links:** edit the `social` block. An empty string hides that icon. `socialLabel` sets the name shown next to them.
- **Menu items:** edit `nav`. **"Join Now" button:** edit `joinNow`.
- **Text of the WhatsApp greeting:** edit the `whatsapp` block.

A few places contain the phone number as plain text and are worth a search if you change it: the `<script type="application/ld+json">` block and address in `index.html` (search engine data), the description line in `contact.html`, and the "Easy to reach" text in the `features` list of `config.js`.

## 4. How to add images to the gallery

1. Put the image files in the **`gallery/`** folder (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` or `.avif`).
2. Run `python3 tools/build.py`.
3. Refresh `gallery.html`.

To remove an image, delete the file and run `build.py` again.

**Why the build step?** A plain website cannot read the contents of a folder by itself. `build.py` scans `gallery/` and writes the list to `js/gallery-list.js`. If you cannot run Python, edit `js/gallery-list.js` by hand: it is just a list of file names.

**Which files appear:** every image in `gallery/` except those starting with `hero-` or `category-` (those are used on the home page). To change this rule, edit `GALLERY_EXCLUDE_PREFIXES` at the top of `tools/build.py`. Product photos (`<slug>.jpg`) do appear in the gallery.

**Captions:** the file name, tidied up. `mango-farm-visit.jpg` shows as "Mango Farm Visit". Product photos show the product name.

**Placeholders:** `tools/make_placeholders.py` fills in any missing picture. Replace them by saving real photos with the same file name. Files that don't exist show a neutral "Image coming soon" picture rather than a broken icon.

**Lightbox:** click any picture to enlarge. Use the arrow keys or the on-screen arrows to move, and Esc to close.

## 5. How to deploy

The site is plain static files, so any host works. **Upload the whole folder contents, keeping the structure.**

### GitHub Pages (free)
1. Create an account at github.com and a new repository, for example `bhagyaveda`.
2. Upload all files (drag and drop in the web page, or use `git push`). `index.html` must be at the top level of the repository.
3. Open the repository → **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
5. After a minute your site is live at `https://<your-username>.github.io/bhagyaveda/`.
6. Custom domain (optional): in the same Pages screen, enter your domain and add the DNS records GitHub shows you.

All links in the site are relative, so it works in a sub-folder like `/bhagyaveda/` without changes.

### Netlify or Cloudflare Pages (free)
Drag the project folder onto the Netlify "Deploy manually" area, or connect the repository. No build command is needed and the publish directory is the project root.

### Ordinary web hosting (cPanel, Hostinger, GoDaddy, etc.)
Upload everything into the `public_html` folder (or your domain's folder) with the file manager or FTP. Keep `index.html` at the top.

### After you go live
- Open every page on your phone and check the call and WhatsApp buttons.
- Test the inquiry form once, end to end.
- Add your live address to `<link rel="canonical">` and a `sitemap.xml` if you want to help search engines (optional).

## 6. How the inquiry form and WhatsApp work

The form on `contact.html` has: **Name, Phone, Email, Message, Product interest**.

1. The visitor fills in the form. Name and Phone are required; Email is checked only if given.
2. On **Send on WhatsApp**, JavaScript (in `js/main.js`, function `initContact`) checks the fields, then builds a message like:
   ```
   Hello Bhagyaveda, I would like to enquire.

   Name: Test User
   Phone: 98765 43210
   Email: a@b.com
   Product interest: Samarth Well Heart
   Message: Need price and dosage
   ```
3. It opens `https://wa.me/919322654624?text=<that message>` in a new tab. On a phone this opens the WhatsApp app with the message ready. On a computer it opens WhatsApp Web or the desktop app.
4. The visitor presses Send in WhatsApp. **The message is only sent when they press Send there.**

Good to know:
- Nothing is stored on your website or any server. There is no database or email.
- The number comes from `contact.whatsappNumber` in `js/config.js`. The greeting line comes from `whatsapp.greeting`.
- The **Enquire Now** button on a product opens `contact.html?product=<slug>#inquiry`, which pre-selects that product in the drop-down.
- If a browser blocks the new tab, a link "tap here to send your enquiry" appears under the form.
- The floating WhatsApp button (bottom right) opens a chat with `whatsapp.floatingMessage`. The floating phone button uses `tel:`.

## 7. How to add new pages in the future

1. **Copy an existing page**, for example `about.html`, and rename it (`faq.html`).
2. Change the `<title>`, `<meta name="description">`, `<meta name="keywords">` and the Open Graph lines in the `<head>`.
3. Change `data-page="about"` on the `<body>` tag to a new name (for example `faq`).
4. Replace the content inside `<main id="main"> … </main>`. Keep these parts as they are on every page, because they load the shared header, footer and buttons:
   ```html
   <div id="site-topbar"></div>
   <header id="site-header"></header>
   ...
   <footer id="site-footer"></footer>
   <script src="js/config.js"></script>
   <script src="js/products.js"></script>
   <script src="js/gallery-list.js"></script>
   <script src="js/main.js"></script>
   ```
5. **Add it to the menu:** in `js/config.js`, add `{ label: "FAQ", href: "faq.html" }` to `nav`.
6. **Highlight it as the current page:** in `js/main.js`, function `buildHeader`, add a line to the `isCurrent` test (copy the pattern used for `gallery.html`).
7. Use the ready-made classes from `css/style.css` (`.section`, `.container`, `.card`, `.btn`, `.product-grid`, `.page-banner`, and so on) so the page matches the rest of the site.

To show products on a new page, add an empty container such as `<div class="product-grid" id="my-grid"></div>` and, in `js/main.js`, call `renderGrid($("#my-grid"), slugsToProducts(["success-ortho", "withamax"]))`.
